# Network Design Sekolah

## Deskripsi

Simulasi jaringan sekolah menggunakan Cisco Packet Tracer.

## Fitur

- VLAN Guru
- VLAN Laboratorium
- VLAN Tata Usaha
- Routing antar VLAN

## IP Address Plan

| VLAN | Network |
|--------|--------|
| 10 | 192.168.10.0/24 |
| 20 | 192.168.20.0/24 |
| 30 | 192.168.30.0/24 |

## Tools

- Cisco Packet Tracer

## Hasil

Seluruh VLAN dapat berkomunikasi melalui router.
